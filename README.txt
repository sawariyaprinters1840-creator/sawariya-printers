SAWARIYA PRINTERS WEBSITE
=========================

Files:
- index.html
- assets/ (images cropped from the reference screenshot)

LOCAL PREVIEW:
1. Keep the folder structure unchanged.
2. Double-click index.html, or open it in Chrome.

DEPLOY ON RENDER:
1. Create a GitHub repository.
2. Upload index.html and the assets folder.
3. On Render choose New > Static Site.
4. Connect the GitHub repository.
5. Build command: leave blank.
6. Publish directory: .
7. Deploy.
